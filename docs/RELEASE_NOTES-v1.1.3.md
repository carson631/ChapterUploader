# ChapterUploader v1.1.3

本次只有一个功能改动：**定时发布一次最多 21 章**（平台硬限制），其余是配套的提示与文档。

---

## 1. 一次最多 21 章

番茄的定时发布接口对单批数量有硬限制，一次最多 21 章，超出的会被平台拒绝。
以前软件会照着「发布范围」把区间里所有草稿一次性全排上，区间填大了就整批失败。

现在的行为：

| 位置 | 表现 |
|---|---|
| 排期提示行（排期卡片里那行小字） | 点之前就能看到：「**共 21 章（平台一次最多 21 章，余下 57 章留到下一批）· 每天 3 章（19:00 / 19:05 / 19:10）· 7 天发完 · 最后一章 2026-11-12 19:10**」 |
| 点「开始定时发布」时 | 只排前 21 章；弹窗说明本次排到第几章、下一批该从第几章开始 |
| 日志 | `平台一次最多 21 章：本次只排前 21 章，第 193 ~ 249 章（57 章）留到下一批（这批发完再点一次即可）` |
| 结束 | 再提示一遍 `还有 57 章没排（从第 193 章起）：等这批发出去后，把范围改成从第 193 章开始再点一次` |

判断是按**实际排进去的章数**算的，不是按区间长度：区间 `172 ~ 249` 共 78 个章号，
但其中只有草稿才算数（已发布 / 已定时 / 回收站都跳过），所以草稿不足 21 章时不会截断。

> 21 章是**平台上限**，不是可配置项；想多排就分几批，每批之间等前一批发完即可。

**为什么要分批而不是一次发完**：定时发布提交后状态变 `5`（已定时发布），
再排下一批时这些章会被自动跳过，所以直接接着改范围点第二次就行，不会重复排期。

## 3. 升级方式

覆盖 `dist/` 里的 `ChapterUploader.exe` 即可，配置（书名、路径、模式）都存在本机注册表/配置里，不会丢。
便携版直接解压新的 `ChapterUploader-v1.1.3-win64-portable.zip`。
