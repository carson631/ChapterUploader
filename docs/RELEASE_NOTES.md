# ChapterUploader v1.1.0

配套「阅文·作家助手」（Electron 客户端）的章节批量上传 / 草稿校对 / **定时发布**工具。通过 DevTools
协议（CDP）直接操作客户端页面，不模拟鼠标坐标，也不改动客户端本体（只加一个调试端口开关，可随时还原）。

## 这个版本加了什么

**一句话：新增第三种模式「定时发布草稿」——进书后自动切到「草稿」列表，按区间逐章点「发布」，
勾「定时发布」，在日历里选日期、在时间面板选时分并点「确定」，最后点「定时发布」。**

### 定时发布

- 界面新增「模式 → 定时发布草稿」，配一张排期卡片：**起始日期 / 起始时间 / 每天几章 / 间隔几分钟**
- 默认规则就是起点常用的节奏：**每天 3 章，从 19:00 开始，每隔 5 分钟一章** → 19:00 / 19:05 / 19:10；
  第二天再从 19:00 重新开始
- 起止章号沿用「发布范围：第 N 章 ~ 第 M 章」，先把客户端的全量目录读回来：
  **只有状态为「草稿」的章才会排期**，已发布 / 已定时发布 / 回收站一律跳过并在日志里列出来
- 表格在开跑前就把每一章的定时时间算好显示出来（编号 / 定时时间 / 标题 / 状态），跑的过程中逐行更新
- 起始时间如果已经过去（比如今天 19:00 已经过了），会自动顺延到第二天同一时间，并在日志里说明
- 勾「演练：只填表不提交」时，会逐章打开发布弹窗、勾定时发布、选好日期时间，核对无误后关掉弹窗——
  **不点「定时发布」**，适合第一次先把流程跑一遍

### 日期/时间为什么要「点面板」

客户端的日期、时间输入框是 ant-design-vue 的 Picker：**直接往 input 里写 value 只改显示，
组件内部状态不变，提交时用的还是旧时间**。所以这里全部走真实交互：

| 步骤 | 做法 |
|---|---|
| 日期 | 点输入框 → 等日历面板弹出 → 需要时按 `.ant-picker-header-next-btn` 翻月 → 点 `td[title="2026-11-06"]` 里当月的那一格 |
| 时间 | 点输入框 → 时间面板里点小时列、分钟列 → **点面板底部的「确定」** |
| 核对 | 填完把两个输入框的真实值回给 C++，和预期不一致就重试一次，仍不一致就**放弃这一章**，绝不带着错的时间提交 |

## 已知边界

- 发布是**逐章**操作：客户端没有批量发布入口，一章一次弹窗
- 客户端对定时发布有平台侧限制（例如最早/最晚可预约时间、每日发布上限、审核），被拒时日志会带上页面提示
- 每隔 5 分钟、每天 3 章是默认值，可在界面上改；改完表格预览立刻重算
- 「发布」按钮的位置依赖 `#btn-group-chapter`（写作页右上角）；客户端大版本升级后可能需要调选择器
